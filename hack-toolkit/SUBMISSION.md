# Simple Hack package preparation — 0.2.12 review draft

[Open ChatGPT Plugins](https://chatgpt.com/plugins). Click **Add**, then choose **Add custom MCP server**. Name it **Simple Hack**, paste `https://simple-hack.app/mcp`, and save. In the sign-in window, sign in with Google or an email code, then choose **Allow**. In a chat, pick Simple Hack from the **+** menu, or just ask. No plugin or listing publication is part of this update.

[Open Claude connectors](https://claude.ai/new?modal=add-custom-connector#customize/connectors/yours). Name it **Simple Hack**, paste `https://simple-hack.app/mcp`, and choose **Add**. In the sign-in window, sign in with Google or an email code, then choose **Allow**. The connector works in the Claude web, desktop, and phone apps.

All five skills in the 0.2.12 ZIPs use the signed-in Simple Hack connector at `https://simple-hack.app/mcp`. The person signs in through their app's trusted browser window; the skills do not ask for or handle an emailed sign-in code, API key, password, passcode or team key in chat. Each skill declares its MCP dependency in `agents/openai.yaml`. The primary `simple-hack-skills-only-0.2.12.zip` contains the five skills, manifest and icons, with no `mcp.json`; the connection must be available separately in the workspace. The full OpenAI draft includes `mcp.json` for the same URL. Neither ZIP has an app binding.

The skills cover hosted organiser, participant, judge, team website and custom event website workflows. They include only packaged organiser and storage references; no registration, credential exchange, remote installer or live instruction-fetch reference is included. The static website and KV/SQLite/file guidance uses the connector's role and site scope. Each resource has a storage preset (public, inbox, wall, records, personal, board or private) that sets who may read, add, edit and delete; the owner is the team on a team site and the organisers on a custom event website, signed in on the site only until the team's deadline or the event's end. Event signup and management stay on the trusted Simple Hack apex. The 1,000,000-byte allowance pools KV, SQLite and raw files per website, separate from deployed assets and retained versions.

The 0.2.12 `simple-hack-claude` and direct-skills ZIPs contain the same reviewed skill snapshot. The public Claude marketplace source may still contain an older release; this package does not update or endorse that listing. Older 0.1.x and 0.2.0–0.2.5 toolkit ZIP downloads were withdrawn from the public site because their instructions had not passed this review. Historic bytes remain in Git history, not on the download site. First-party older immutable ChatGPT ZIP URLs return HTTP 410.

The listing retains Simple Hack's name, publisher, icon, support/privacy/terms links and default prompts. OpenAI upload, portal checks, recording, reviewer access, marketplace submission and publication have not occurred. This source package is a prepared draft for owner review, not an approved directory listing. Do not include private credentials, keys, codes or fixture files in a ZIP.
