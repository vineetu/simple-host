# Simple Hack package preparation — 0.2.5 review draft

All five skills in the 0.2.5 ZIPs use the signed-in Simple Hack connector at `https://simple-hack.app/mcp`. The person signs in through their app's trusted browser window; the skills do not ask for or handle an emailed sign-in code, API key, password, passcode or team key in chat. Each skill declares its MCP dependency in `agents/openai.yaml`. The primary `simple-hack-skills-only-0.2.5.zip` contains the five skills, manifest and icons, with no `mcp.json`; the connection must be available separately in the workspace. The full OpenAI draft includes `mcp.json` for the same URL. Neither ZIP has an app binding.

The skills cover hosted organiser, participant, judge, team website and custom event website workflows. They include only packaged organiser and storage references; no registration, credential exchange, remote installer or live instruction-fetch reference is included. The static website and KV/SQLite/file guidance uses the connector's role and site scope. A resource's `signed-in` policy covers the whole resource, so per-person data on team sites keeps existing private APIs; event signup and management stay on the trusted Simple Hack apex. The 1,000,000-byte allowance pools KV, SQLite and raw files per website, separate from deployed assets and legacy saved data.

The 0.2.5 `simple-hack-claude` and direct-skills ZIPs contain the same reviewed skill snapshot. The public Claude marketplace source may still contain an older release; this package does not update or endorse that listing. Older 0.1.x and 0.2.0–0.2.4 toolkit ZIP downloads were withdrawn from the public site because their instructions had not passed this review. Historic bytes remain in Git history, not on the download site. First-party older immutable ChatGPT ZIP URLs return HTTP 410.

The listing retains Simple Hack's name, publisher, icon, support/privacy/terms links and default prompts. OpenAI upload, portal checks, recording, reviewer access, marketplace submission and publication have not occurred. This source package is a prepared draft for owner review, not an approved directory listing. Do not include private credentials, keys, codes or fixture files in a ZIP.
