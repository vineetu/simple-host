Make the event. Build the projects. Judge the work.

Simple Hack has a skill for each role. Organisers run the event and can publish its public website, participants join teams, judges score projects, and teams plan and publish their own sites. Every skill works with the Simple Hack connector or the REST API.

Download status: the five skills and 0.2.2 ZIPs are available here for direct use and inspection. They describe event websites, icons, public data and account preferences. The shared Website Deploy guides also cover ordinary Simple Host KV, SQLite and files; Simple Hack team sites keep their own declared-data backend. OpenAI upload and external marketplace review are separate steps and have not happened. The primary skills-only ZIP has no MCP server. Read the submission notes.

Connect Simple Hack

Start at Simple Hack's Get started page for the five raw skills and coding-agent installation. In ChatGPT, add https://simple-hack.app/mcp as a custom connector when that option is available, then sign in to Simple Hack. One connection works across your events and roles. To publish a team site, select the current team with hack_select_team. The skills also guide the REST API with a separate simple-hack.app key when no connector is available.

In Claude Code, install the published marketplace plugin with /plugin marketplace add vineetu/simple-hack-plugin and /plugin install simple-hack@simple-hack-marketplace. The downloaded Claude ZIP is the next local draft until the owner publishes it.
