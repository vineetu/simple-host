What the connection covers

  • List events and roles, check an event name, create and edit a draft.
  • Read or change an event stage and judging rubric.
  • Export scores and results CSVs.
  • Connect as a participant’s team to publish that team’s site.
Scope and access

The organiser connection manages only events where the signed-in person is an organiser. A team connection is bound to one team’s site. The skill also covers browser and direct API steps that are outside the ten organiser tools.
