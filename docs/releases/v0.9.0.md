# Simple Host and Simple Hack 0.9.0

This is the first release built as two programs from one tag:

- `simple-host` is the platform alone.
- `simple-hack` is the platform with Simple Hack added.

Both programs have the same version, `0.9.0`. The separate `hack-v` tags have ended.

## Install fresh

There is no upgrade path from an earlier release. A new install starts on this version.

## What is in this release

- **Storage uses row rules.** Rules decide who can read and write each row of SQLite and key-value data. On hosted Simple Host, presets end on 17 December 2026.
- **Key-value data lives in one file per site.**
- **A backup and restore script is included.** `deploy/shared/upgrade.sh` backs up the database, the files and the configuration together. `deploy/shared/upgrade.sh --restore` puts all three back.
- **The static file server is included but switched off.** It is not for production use yet.
