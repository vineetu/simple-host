<Steps>

1. Get a key and keep it in your local environment as `SH_KEY`.

   {/* brand:host */}
   Open your sites page, **Settings**, then **Keys**. Name the key, press **Create key**, and copy it when shown.
   {/* /brand */}
   {/* brand:hack */}
   For an account key, open **Account**, **Danger zone**, then **New key**. Confirm that this replaces your old key and disconnects connected apps. For team publishing, use **Website**, then **Advanced: command line and API key** instead.
   {/* /brand */}

2. Read your account from a terminal:

   ```sh
   curl -H "X-API-Key: $SH_KEY" https://@DOMAIN@/v1/me
   ```

3. Publish one file.

   {/* brand:host */}
   ```sh
   curl -X POST https://simple-host.app/v1/sites/hello/files \
     -H "X-API-Key: $SH_KEY" -H 'Content-Type: application/json' \
     --data '{"files":{"index.html":"<!doctype html><h1>Hello</h1>"}}'
   ```
   {/* /brand */}
   {/* brand:hack */}
   With your team's key, replace `TEAM` with the site name shown under Website:
   ```sh
   curl -X PUT 'https://simple-hack.app/v1/sites/TEAM/files?create=1' \
     -H "X-API-Key: $SH_KEY" -H 'Content-Type: application/json' \
     --data '{"files":{"index.html":"<!doctype html><h1>Hello</h1>"}}'
   ```
   {/* /brand */}

4. Read `code` in an error body shaped as `{"error":"...","code":"..."}`. Branch on the code, and display `error` to the person. Honor `Retry-After` before retrying a limited request.

</Steps>

{/* brand:hack */}
Announcement POST accepts optional `pinned`; PUT accepts `pinned` alone to pin/unpin or title and body together to edit. GET and the public event feed return `body_html` (safe HTML to insert as-is) and `pinned`, pinned first. The organiser-only POST `/v1/hack/events/{slug}/announcements/preview` takes body and returns body_html without saving. The MCP equivalents are `hack_post_announcement`, `hack_edit_announcement` and `hack_get_announcements`, using a body object for writes. Text supports labelled links `[label](https://...)`, bold, bullets and line breaks; only http/https links. Standalone Zoom, Meet, Teams and YouTube addresses become cards. YouTube thumbnails come from i.ytimg.com.
{/* /brand */}
