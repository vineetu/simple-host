<Steps>

1. [Connect your AI app](/get-started), or sign in and press **Create event**.
2. Ask: “Create a hackathon called Better Commutes.” Add the event dates, then open the event's **Home**.
3. In **Event page**, fill in the event details. In **Settings → Entries**, choose what teams hand in. In **Settings → Judging**, set the rubric. Tracks live on **Event page → Tracks**.
4. Use **Home** to open sign-up. Copy the **Join link** from **Home** and send it to participants; copy the **Judge link** there for judges.
5. Follow the next-step button on **Home** to start building, close entries, start judging, and publish results. Confirm each stage change. **Your events** stays in the pane; open another event there to switch.

</Steps>
