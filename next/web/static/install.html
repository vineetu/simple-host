ChatGPTOn the web

Add custom MCP server

The fastest way: one address to paste.

  1. Open ChatGPT Plugins.
  2. Click Add, then choose Add custom MCP server.
  3. Name it Simple Host, paste this address, and save.
    https://simple-host.app/mcp
  4. A sign-in window opens. Choose Continue with Google, or enter your email and the 6-digit code we send, then choose Allow.

ChatGPT keeps the tool list from the day you added Simple Host. When Simple Host adds features, open ChatGPT Plugins, choose Simple Host, then Refresh.

Or add it by its address, in developer mode:

  1. Open Settings, then Apps & Connectors, then Advanced settings, and turn on Developer mode.
  2. Back in Apps & Connectors, choose Create.
  3. Name it Simple Host, and paste this address as the MCP server URL:
    https://simple-host.app/mcp
  4. Choose OAuth for authentication, then Create.
  5. Sign in with Google or an email code, then choose Allow.

Add the skill

Download skills.zip. Unzip it into your agent's skills directory (it holds one folder, simple-host), then restart the agent.

  • Claude Code: ~/.claude/skills/
  • Codex: ~/.agents/skills/; Cursor: ~/.cursor/skills/
  • opencode: ~/.config/opencode/skills/; Hermes: ~/.hermes/skills/; OpenClaw: ~/.openclaw/skills/

On Windows, replace ~ with your user profile directory.

Can I use my own domain?

Yes. Or pick a free name.simple-host.app address.

Can I run my own?

Yes, on one small server with Docker Compose. See Run your own copy.

Your public page

Your own address lists the sites you switch on for it. Or ask your connected app to "make this my home page" to show one site there instead.

Run your own copy

You need a small server with Docker and Docker Compose, and a domain you control.

  1. Download compose.yaml and .env.example from the source repository. Save .env.example as .env.
  2. In .env, set DOMAIN to your domain.
  3. Point DOMAIN and *.DOMAIN at the server with your DNS provider.
  4. Run docker compose up -d.
  5. Open https://DOMAIN/setup and finish setup there. It checks your DNS.

On your own copy, sites live at <site>--<handle>.DOMAIN.

Upgrade

Make a backup first, then pull and restart:

docker compose exec db pg_dump -U simplehost simplehost > backup.sql
docker compose pull && docker compose up -d
