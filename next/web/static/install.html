Get started

Connect your AI app to Simple Host with one address. Then ask it for a page, a form or a small tool. It publishes the site and gives you the link.

The connector address is:

https://simple-host.app/mcp

Claude

  1. Open Settings, then Connectors.
  2. Choose Add custom connector.
  3. Paste the address above.
  4. Sign in to Simple Host with your email or Google.
  5. Approve the connection.

ChatGPT

  1. Open Settings, then Connectors (also called Apps). Turn on developer mode.
  2. Add a new connector and paste the address above.
  3. Sign in to Simple Host and approve.

Other apps that support MCP

Find where the app adds a remote MCP server or connector. Paste the address above. Sign in and approve when asked.

You can see connected apps in your dashboard and disconnect any of them there.

Publish from a script

Make a key in your dashboard. It is shown once. A key acts as you, with your rights. Then send files to one route:

curl -X PUT https://simple-host.app/v1/sites/my-site \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"files":{"index.html":"<h1>Hello</h1>"}}'

The reply holds the address of your site. The routes are in the API reference.

Run your own copy

You need a small server with Docker and Docker Compose, and a domain you control.

  1. Download compose.yaml and .env.example from the source repository. Save .env.example as .env.
  2. In .env, set DOMAIN to your domain.
  3. Point DOMAIN and *.DOMAIN at the server with your DNS provider.
  4. Run docker compose up -d.
  5. Open https://DOMAIN/setup and finish setup there. It checks your DNS.

On your own copy, sites live at <site>--<handle>.DOMAIN.

Upgrade

Make a backup first, then pull and restart:

docker compose exec db pg_dump -U simplehost simplehost > backup.sql
docker compose pull && docker compose up -d
