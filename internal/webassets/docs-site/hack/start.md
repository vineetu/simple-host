# Run an event

1. [Connect your AI app](/get-started), or sign in and press **Create event**.
2. Ask: “Create a hackathon called Better Commutes.” Add the event dates, then open the event's **Home**.
3. In **Event page**, fill in the event details. In **Settings → Entries**, choose what teams hand in. In **Settings → Judging**, set the rubric before Judging starts. Tracks live on **Event page → Tracks**.
4. Follow the checklist on **Home**. Unfinished optional rows have **Not needed** and **Use this item**. Completed rows show the recorded facts. Use **Home** to open sign-up. Copy the **Join link** from **Home** and send it to participants; copy the **Judge link** there for judges. To learn what any setting or option means, or what happens if you change it, press **Ask** at the bottom right of any organiser screen: it answers in a few lines and links to where to change it. It never changes anything itself.
5. Follow the next-step button on **Home** to start building, close entries, start judging, and publish results. Confirm each stage change. **Your events** stays in the pane; open another event there to switch, including its mark when the pane is collapsed.

Use `hack_get_checklist` with the event slug and `role: "organiser"` for current tasks and the next action. Confirm changes before writing.

Publish from Home: the confirmation shows current standings and lets you order tied teams, retaining valid saved choices. Judging opens scoring; Finish judging moves to Results and locks it. Moving back to Judging reopens scoring. If standings change, Home offers Publish again, including after End.

Choose **Organisers who also judge** in Settings → Judging and save with the assignment mode. Organisers start unticked; organisers with existing scores start ticked. This same judge list supplies queues, assignments and counts. Starting Judging shows the mode, judges per team, judge names and coverage with links to fix them; you can start anyway. Informational checklist rows have no button.

Account → **Connected AI apps** lists your connections and lets you disconnect each one. Open **Connect another app** for setup steps, including **Other AI apps**. With no connections, **Connect an AI app** opens automatically.

Home offers **Close entries** even without an entry deadline.

In **Event page → About → Prizes**, set optional **Prize for 1st / 2nd / 3rd** values to show the place and prize on winner cards. Places with prizes appear in winners-only results, including when ranks are hidden.

In **Announcements**, press **Add link** beside Message, enter a Label and Address, and check **Preview** before posting. Announcements support clickable http(s) addresses, labelled links, bold, bullets and line breaks. Standalone Zoom, Meet, Teams and YouTube links become cards without fetching linked pages. Organisers can preview before posting and pin one announcement, replacing the previous pin; it appears first for participants and judges. Email carries matching HTML buttons and full addresses in plain text. Use the row menu → **Pin to top** or **Unpin**. Editing never resends email.
