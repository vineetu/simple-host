# Join an event

1. Open the organiser's join link and sign in. Enter your name if asked, read the code of conduct, and accept it.
2. Open **Team**. Create a team or request to join one. Wait for approval when the organiser or team requires it.
3. Open **Website** and follow **Publish from your AI app**. Ask it to build your team's idea and publish to the selected event and team.
4. Open **Entry**, fill in the requested fields, and submit before your team's deadline.
