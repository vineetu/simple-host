Install the skills manually

Most coding agents take one command: npx skills add vineetu/simple-host. It finds your agent's skills folder by itself. Chat apps (ChatGPT, Claude, Grok) add the connector instead: see Get started. The rest is for when neither fits.

Skills folders

  • Claude Code: ~/.claude/skills/ · Windows $env:USERPROFILE\.claude\skills\
  • ChatGPT desktop, Codex CLI: ~/.agents/skills/ · Windows $env:USERPROFILE\.agents\skills\
  • Cursor: ~/.cursor/skills/ · Windows $env:USERPROFILE\.cursor\skills\
  • opencode: ~/.config/opencode/skills/ · Windows $env:USERPROFILE\.config\opencode\skills\
  • Hermes: ~/.hermes/skills/ · Windows $env:USERPROFILE\.hermes\skills\
  • OpenClaw: ~/.openclaw/skills/ · Windows $env:USERPROFILE\.openclaw\skills\
  • Anything else: the skills folder it reads. The files are the same.

Put the three skill folders (website-deploy, website-deploy-builder, connect-domain) straight into the skills folder, with no extra folder around them.

macOS / Linux (Claude Code shown)

mkdir -p ~/.claude/skills && curl -fsSL https://simple-host.app/skills.zip -o /tmp/sh-skills.zip && unzip -o /tmp/sh-skills.zip -d ~/.claude/skills

install.sh does the same download and unzip. Read it, then run it with sh.

Windows PowerShell

New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Invoke-WebRequest https://simple-host.app/skills.zip -OutFile "$env:TEMP\sh-skills.zip"
Expand-Archive "$env:TEMP\sh-skills.zip" "$env:USERPROFILE\.claude\skills" -Force

A symlink error on Windows means the installer needs admin rights: add --copy to the npx command instead.

GitHub Copilot CLI

Copilot sandboxes its own ~/.copilot folder, so add each skill by address:

copilot skill add https://simple-host.app/skills/website-deploy/SKILL.md
copilot skill add https://simple-host.app/skills/website-deploy-builder/SKILL.md
copilot skill add https://simple-host.app/skills/connect-domain/SKILL.md

or with the universal installer:

npx skills add vineetu/simple-host -g -a github-copilot -s website-deploy --copy -y
npx skills add vineetu/simple-host -g -a github-copilot -s website-deploy-builder --copy -y
npx skills add vineetu/simple-host -g -a github-copilot -s connect-domain --copy -y

Hermes and OpenClaw

hermes skills install https://simple-host.app/skills/website-deploy/SKILL.md --name website-deploy

OpenClaw finds any SKILL.md under ~/.openclaw/skills/. A single-file install still works: website-deploy's SKILL.md cites each of its reference documents by full address.
