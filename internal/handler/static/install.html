Before you publish

Who can see my site?

Anyone with the link. Sites are served on the public internet at sites.simple-host.app/<you>/<site>/ — there is no sign-in in front of them. A site can be unlisted from your profile page, but treat a link as public. There is no way to put a password on a site — if a page must not be readable by strangers, do not publish it here.

Is the data my site collects private?

No. Sites and their data are public to anyone with the link. The per-site store — shared state and collections, which is what powers RSVP forms, counters and guestbooks — can be read by anyone who can reach the site. On the shared sites.simple-host.app host anyone can write to it too: a page there saves without any sign-in, and that data can be changed by anyone. Connect your own domain and saving gets sign-in — visitors sign in with Google, or a 6-digit code emailed to them, and the page saves on their behalf. A connected site is served only on its domain: the old shared-host link redirects there, and saving happens only there. Your agent can write anywhere with your API key.

The practical version: a sign-up form on a Simple Host site is fine for a party or a team lunch. It is not fine for anything you would mind a stranger reading.

Can someone else change my site?

Not the files. Deploying a new version needs your API key, and today every site has exactly one owner — there is no way to grant a colleague deploy access yet. The data your site collects is a different story: see the answer above.

What is this actually good for?

Anything that is a page: a portfolio, a résumé, an event invite, a launch or coming-soon page, docs, a menu, a mockup you want notes on. Add the backend when the page needs to remember something across visitors — an RSVP list, a vote, a counter, a guestbook.

What it is not: nothing runs on the server. No PHP, no Node, no Python, no database you control, no server-side rendering. If your idea needs a login system or private records, it needs a different host.

How much does it cost, and what happens to my site?

Nothing, and it stays up until you delete it. The server keeps recent versions of each site so you can roll back. Deleting a site removes its files, every version, and its stored data — that is not reversible.
