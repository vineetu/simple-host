ChatGPTOn the web

Add custom MCP server

The fastest way: one address to paste.

  1. Open ChatGPT Plugins.
  2. Click Add, then choose Add custom MCP server.
  3. Name it Simple Host, paste this address, and save.
    https://simple-host.app/mcp
  4. A sign-in window opens. Sign in with Google or an email code, then choose Allow.

ClaudeWeb, desktop, and phone

Install the Simple Host plugin

One step: it adds the connector and the skills together, so Claude follows Simple Host's own instructions.

  1. Open Claude, then Customize, then Plugins, then Discover.
  2. Search for Simple Host, select it, then choose Add.

Connector only

  1. Open Claude, then Settings, then Connectors, then Browse connectors.
  2. Search for Simple Host, choose Connect, sign in, then choose Allow.

Both work on web, desktop, and phone.

Claude CodeOne command
  1. Run this in your terminal. It adds the connector and the skills:
    claude plugin marketplace add vineetu/simple-host && claude plugin install simple-host@simple-host
  2. In Claude Code, type /mcp, choose simple-host, then Authenticate.
  3. Sign in once in the window that opens, then choose Allow.
CodexOne command
  1. Run this in your terminal. It adds the skills and the connector:
    npx skills add vineetu/simple-host -g -a codex -y && codex mcp add simple-host --url https://simple-host.app/mcp
  2. Sign in once in the window that opens, then choose Allow.
  3. Start Codex and ask for a site.
OpenClawOne command
  1. Run this on the computer where OpenClaw runs. It adds the skills and the connector:
    npx skills add vineetu/simple-host -g -a openclaw -y && openclaw mcp add simple-host --url https://simple-host.app/mcp --transport streamable-http --auth oauth && openclaw mcp login simple-host
  2. Open the link it prints, sign in, then choose Allow.
  3. Ask OpenClaw for a site, from any chat you use it in.

If OpenClaw runs on another computer, the browser ends on a page that does not load. Copy the code after code= in its address and run openclaw mcp login simple-host --code followed by the code.

Hermes AgentOne command
  1. Run this on the computer where Hermes runs. It adds the skills and the connector:
    npx skills add vineetu/simple-host -g -a hermes-agent -y && hermes mcp add simple-host --url https://simple-host.app/mcp --auth oauth --connect-timeout 300
  2. Open the link it prints, sign in, then choose Allow. When Hermes asks to enable the tools, press Enter.
  3. Ask Hermes for a site, from any chat you use it in.

If Hermes runs on another computer, the browser ends on a page that does not load. Paste that page's address into Hermes when it asks.

It's live

Your site is online at its own address, and it shows up under Your sites.

Who can see my site?

Anyone with the link can see its pages. Each person’s records lets people add records and see only their own status and history, while you see and update all. Use it for shop orders, RSVPs and event sign-ups, bookings and appointments, applications (jobs, clubs, hackathons), support requests, homework or assignment submissions, survey answers people can revisit, and a waitlist with “my place in line”.

Is it free?

Yes.

Can I use my own domain?

Yes. Or pick a free name.simple-host.app address.

Can I run my own?

Yes: on one small server with Docker, or on your company's Kubernetes. The setup helper asks a few questions and writes the install command and settings: Run your own → Set up · In your organization → Set up.

Your home page

Ask your connected app to “make this my home page”. Your person address opens your showcase or a site you choose. In Your showcase, save a short bio, pin projects and set their order. Custom homes can list projects from the live showcase feed. These controls also work on small-box installs.
