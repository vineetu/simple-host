Privacy Policy

Simple Host (simple-host.app) · last updated 2026-08-14

Simple Host is a static-website hosting service. This policy covers what data it handles, including when the service is used through an integration such as a ChatGPT GPT, an MCP server, or an AI coding agent.

What we collect

  • Email address — for sign-in. We collect it when you verify a one-time emailed code, or when Google or GitHub asserts a verified address. That address is your account username. Signing in on someone else's hosted page (an RSVP, a guestbook) creates the same kind of account so we know who wrote — we do not email you a key, show you a dashboard, or give that page your API key.
  • Provider account id — Google sub or GitHub numeric id, stored so the same person signing in again is the same account. We also keep a snapshot of the verified email the provider last sent. We do not store your name, picture, or access token.
  • Your API key — a random token that authenticates owner requests (deploy, delete, rollback). Stored to look up your account. It is disclosed only after an owner-intent sign-in (emailed code, or “Sign in with Google” on this dashboard). A session cookie on a hosted site is not an API key and cannot deploy or delete anything.
  • Sites you deploy — the files you upload, their versions, and the site name. Deployed sites are served publicly on the internet at sites.simple-host.app/<handle>/<site>/. Privacy (password lock) is available on a connected custom domain.
  • Per-site state — any data a site saves via the state/collections API. This is public to that site's audience by design; do not put secrets in it.
  • Basic request metadata — IP address and timestamps, used for rate-limiting and abuse prevention.

How we use it

  • To authenticate you, host and serve your sites, and operate the per-site backend. One account is used across every site you sign into and every site you own — we can join those in our database. We do not publish that join to other sites' pages.
  • To enforce rate limits and quotas and to investigate abuse.
  • We do not sell your data or use it for advertising.

Using Simple Host through a GPT or agent

When you use Simple Host through a shared ChatGPT GPT or agent, requests are made with the API key configured in that integration. Anything deployed is public and attributable to the account whose key is used. Do not upload confidential information.

Retention & your choices

  • You can delete any site you own at any time (via the API or the dashboard); deletions remove the served content.
  • Uploaded versions are retained to enable rollback until the site is deleted.
  • To delete your account or data, contact us below.

Third parties

We use an email provider to send sign-in codes, Google and/or GitHub when you choose those buttons (they see that you signed in here), and a hosting provider to run the service. The optional "Create with AI" feature sends your prompt to Anthropic's Claude to generate a site. No other third-party sharing.
