Run, join or judge a hackathon from the AI you already use.

Add Simple Hack to your AI once. Then just ask.

Pick your AI

ChatGPT

On the web, with a plan that supports custom apps.

  1. Open Settings → Security and login and turn on Developer mode.
  2. In ChatGPT’s Plugins, use + to create an app called Simple Hack. Choose OAuth, leave the advanced fields empty and paste this address:
    https://simple-hack.app/mcp
  3. Sign in once in the Simple Hack window that opens, with Google or an email code, then choose Allow.

Claude

Set up on the web or desktop; use it on your phone too.

  1. Open Customize → Connectors → + Add → Add custom connector.
  2. Name it Simple Hack and paste this address. Choose Sign in now and Register automatically if asked, then Add.
    https://simple-hack.app/mcp
  3. Sign in once in the Simple Hack window that opens, with Google or an email code, then choose Allow.

Grok

With access to custom connectors.

  1. Open grok.com/connectors, then New Connector → Custom.
  2. Paste this address:
    https://simple-hack.app/mcp
  3. Sign in once in the Simple Hack window that opens, with Google or an email code, then choose Allow.

GitHub Copilot

In VS Code.

  1. Open the Command Palette, run MCP: Add Server and choose HTTP.
  2. Paste this address, name it simple-hack, save and start the server. Accept the trust prompt.
    https://simple-hack.app/mcp
  3. Sign in once in the Simple Hack window that opens, with Google or an email code, then choose Allow. Use Copilot Chat’s agent mode.
VS Code setup guide

Claude Code / Codex / other coding agents

Run this in a terminal with Node.js installed.

  1. Install the five Simple Hack skills for Claude Code and Codex, then restart your agent:
    npx -y skills add https://github.com/vineetu/simple-host/tree/main/hack-toolkit --global --agent codex claude-code --yes
    For another agent, replace codex claude-code with its name.
  2. Ask your agent to add Simple Hack as a remote HTTP MCP server with OAuth at this address:
    https://simple-hack.app/mcp
  3. Sign in once in the Simple Hack window that opens, with Google or an email code, then choose Allow.

After connecting, select Simple Hack in your chat’s tools and try a prompt below. Your AI may ask for event details or confirmation before opening an event.

Try one of these

Organiser

Create a hackathon called Night Build for next Saturday and Sunday, and give me the join link.

Participant

Join the hackathon with code ab12cd34 and start a team called Night Owls.

Judge

I’m judging Night Build. Show me my next project.

Use your event’s real join code. Judges need the organiser’s judge link first.

What happens next

Your AI helps with the event and gives you the links to share. You can also manage your event, team or judging from Simple Hack on your phone.

Is it free?
Yes. Running an event, joining, judging and hosting team sites are free.
Who sees the scores?
By default, only winners are public. After results are published, teams privately see their own scores and feedback. Organisers see all results and can choose to publish more rankings or scores.
Do I need a laptop?
No. You can run, join or judge from a phone. Coding agents need a computer.
Where do team sites live?
At team.event.simple-hack.app, using your team and event names.
Can I run my own?
Yes. Self-host a hackathon with Simple Host.
Other ways to install

Download the five skill folders for your coding agent, or upload the skills-only plugin ZIP in a ChatGPT workspace that supports custom plugin uploads. Connect https://simple-hack.app/mcp as above to use them.
