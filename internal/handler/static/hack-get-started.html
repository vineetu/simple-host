Let a coding agent install them

Give your agent the instructions below. It can fetch the five folders and their reference files from this site. Read the chosen skill before acting, and use its connector path when those tools are available; otherwise follow its REST path with your Simple Hack account key.

Install the five Simple Hack skills from https://simple-hack.app/skills.zip into your skills directory. Read the SKILL.md for the role I ask about and its linked references. The source skill files are at https://simple-hack.app/v1/skills/<name>/SKILL.md. Do not install connect-domain for this task.

Codex or Claude Code

For a local coding agent, download the ZIP and extract the five folders into its skills directory. These commands save the file before installing it.

curl -fsSLo simple-hack-skills.zip https://simple-hack.app/skills.zip
mkdir -p "$HOME/.codex/skills"
unzip -q -o simple-hack-skills.zip -d "$HOME/.codex/skills"

For Claude Code, replace $HOME/.codex/skills in the last two lines with $HOME/.claude/skills. Then ask your agent to read the skill for your role. The separate Claude marketplace plugin is an optional connection; its new five-skill release has not been published yet.

ChatGPT

  1. Download the skills-only ChatGPT plugin ZIP.
  2. In a ChatGPT workspace that supports custom plugin uploads, upload the ZIP and review its five imported skills. The owner has prepared this package for review; it has not been submitted or published in a marketplace.
  3. If you want connector tools, add https://simple-hack.app/mcp separately as a custom connector where that option is available, then sign in to Simple Hack. The skills also describe REST access when no connector is available.

Opening this page does not install anything into ChatGPT. The ZIP upload and connector setup happen in your ChatGPT workspace.
