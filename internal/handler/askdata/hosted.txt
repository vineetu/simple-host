=== About Simple Host (public summary) ===

Simple Host (https://simple-host.app) hosts static websites and gives every site a small backend for saved data, in the same upload. People mostly never touch it directly: they tell their AI app or coding agent "put this online", and the agent registers, builds and deploys through the Simple Host skill or the Simple Host connector (ChatGPT, Claude, Grok and coding agents such as Claude Code, Codex and Cursor).

What a site gets:
- Its own address, https://<site>.<handle>.simple-host.app/, which is its own browser origin. A person's page lists their public sites at https://<handle>.simple-host.app/. A site can also use a free <name>.simple-host.app name or the person's own domain, with HTTPS.
- Saved data: one shared JSON document per site (state) with atomic operations, and lists (collections) for things like RSVPs, votes and guestbooks. Saved data has a 30-day undo. Pages save with the hosted helper script auth.js.
- Visitor sign-in on the site's own address, with Google or an emailed code, so saves are per person. A list can be made private so only the site's owner can read it (orders, RSVPs, sign-ups).
- Versions and rollback, previews before going live, renames that keep old links working, taking a site offline, analytics of people versus bots, and a download of a site or of all of a person's data.

Accounts: sign in with an emailed six-digit code or Google; no password. Agents use an API key or the connector's sign-in.

Pages are always public to anyone with the address; there is no password lock. Only a private list is private. There is no server-side code for site authors: pages run in the visitor's browser.

Running your own: https://simple-host.app/setup is a setup helper that asks a few questions (or every setting, in Advanced mode) and writes the one-line install command and .env for a small box (one server with Docker), or config.env, a secrets template and the apply commands for Simple Host Enterprise on Kubernetes. It runs in the browser and sends nothing anywhere; every setting is explained in docs/advanced/ of each repository.

It is one Go program, one Postgres database and one folder of files.
